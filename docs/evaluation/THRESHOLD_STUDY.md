# Threshold Study

The threshold study is a calibration-split frontier over the original `UNCALIBRATED_DECISION_SCORE`. It reports eligible count, coverage, precision, false positives, recall, review rate, abstention rate, and worst accepted-slice precision for thresholds 0.1 through 0.9.

No threshold is selected. No runtime policy is mutated. A threshold would require an explicitly approved operating objective, adequate independent groups, calibration evidence, and a later review/decision step.
