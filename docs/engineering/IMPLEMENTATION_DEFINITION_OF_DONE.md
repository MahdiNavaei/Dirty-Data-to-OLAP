# Implementation Definition of Done

An implementation slice is done only when its project-owned contract is versioned, the owner and consumers are recorded, focused tests pass, failure and invalidation behavior is explicit, provenance is retained, source safety is demonstrated, and the handoff receipt identifies exact commands and artifacts.

It is not done when only a stub, static report, synthetic fixture, vendor-native object or happy-path screenshot exists. A milestone may be marked complete only by its owning specialist and required gate; later gates remain pending until their own evidence exists.
